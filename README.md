# Renyi_parking_problem_mathematical_research_project
This is a research project I studied for my Senior Research as a mathematics student. Based on the Renyi parking problem, my main research focuses on different distributions affecting the packing of these cars on a limited parking line. Other files are for experimenting and testing different setups.
Renyi_Research_computing_1000.py is the main file used for the Modified_Renyi_parking_problem.pdf.
